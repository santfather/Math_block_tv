# TEST_PLAN — сценарии приёмки

Прогоняется вручную на реальном ТВ. Статусы: `не проверено` / `проходит` / `падает`.

| ID | Сценарий | Ожидание | Статус |
|---|---|---|---|
| A1 | Смотреть YouTube 15 минут непрерывно | Пауза, показ примера | проходит |
| A2 | Решить пример правильно | Блок снят, счётчик с нуля | проходит |
| A3 | Ответить неправильно | Блок остаётся, новый пример, пауза | проходит |
| A4 | BACK / HOME / повторный запуск YouTube при блоке | Блок возвращается | проходит |
| A5 | 10 мин → закрыть YouTube → открыть → 5 мин | Блок на суммарных 15 мин | проходит |
| A6 | Смена даты/времени на ТВ | Счётчик не меняется | проходит |
| A7 | 10 мин → выключить ТВ → включить через час → 5 мин | Блок на 15 мин | проходит |
| A8 | Блок активен, выключить и включить ТВ | YouTube всё ещё заблокирован | проходит |
| A9 | Полное отключение питания при блоке (`resetOnPowerLoss=false`) | Блок сохраняется | проходит |
| A10 | То же при `resetOnPowerLoss=true` | Состояние сброшено | проходит |
| A11 | Выключить accessibility-сервис в настройках | Сервис возвращается за секунды | проходит |
| A12 | `adb shell am force-stop <pkg>` во время `Counting` | Сервис поднимается, время восстановлено | проходит |
| A13 | PIN + «Разблокировать сейчас» | Блок снят, статистика записана | проходит |
| A14 | 5 неверных PIN подряд | Нарастающая задержка | проходит |
| A15 | Лимит достигнут при активном YouTube (Android 12) | Блок появляется без участия пользователя | не проверено |
| A16 | После обновления YouTube | A1–A5 проходят, версия записана | не проверено |

Примечания по проверке:

- A1–A6 пройдены в фазе 5 (лимиты временно снижались до 60 с / 20 с, затем возвращены).
- A7–A10 — механизм проверен в фазе 6 реальной перезагрузкой ТВ; «потеря питания» имитировалась
  `am force-stop` перед ребутом (чтобы не записался `clean_shutdown=true`). Точная многочасовая
  выдержка A7 и выключение пультом отдельно не прогонялись.
- A11–A12 — проверены в фазе 6 напрямую (см. `DEVICE_NOTES.md`, «Наблюдения фазы 6»).
- A13–A14 — проверены в фазе 7: верный PIN открывает настройки, «Разблокировать сейчас» снимает
  блок (тост + закрытие); четвёртая ошибка PIN подряд запускает паузу с живым отсчётом
  (первые три бесплатны). Детали — в `DEVICE_NOTES.md`, «Наблюдения фазы 7».
- A15 — механизм проверен в фазе 5 (блок появляется без участия пользователя при активном
  YouTube, см. A1); A16 — ожидает обновления YouTube на ТВ.

## Фаза 8: матрица обходов

| Обход | Закрыто / частично / не закрыто + причина |
|---|---|
| Другой клиент YouTube (SmartTube) | **Не закрыто.** Сторонние клиенты на ТВ сейчас не установлены, но приложение не мешает установке и не детектирует неизвестные пакеты. Механизм только один — вручную добавить пакет в «отслеживаемые» (настройки). Ограничить установку может лишь Device Owner (фаза 9) или ограниченный/Kids-профиль. |
| YouTube в браузере | **Закрыто (с оговоркой).** `com.tvwebbrowser.v22` добавлен в дефолтный список и в опции настроек; открытие браузера проверено на ТВ (`foreground -> true`). Оговорка: URL-фильтр невозможен без чтения контента (`canRetrieveWindowContent=false`), поэтому блокируется браузер целиком; другой браузер нужно добавить в список вручную. |
| Cast с телефона | **Частично.** Трансляция запускает тот же `com.google.android.youtube.tv`, который отслеживается (любой путь запуска YouTube ловится — проверено intent-запуском). Прямая трансляция с телефона на ТВ вручную не прогонялась. |
| Отключение accessibility-сервиса | **Закрыто.** `SelfHealer` возвращает службу за ~80 мс (проверено в фазах 6 и 8). |
| Удаление приложения | **Не закрыто.** Без прав Device Owner удаление не блокируется; ТВ настроен с аккаунтом Google, ограниченный/Kids-профиль не заведён. Решение — родительский (Kids) профиль; снятие ограничения — фаза 9 (опционально). |
| «Остановить» приложение в настройках | **Не закрыто.** При `am force-stop`/«Остановить» процесс убит, `SelfHealer`/`BootReceiver` не выполняются, автозапуска нет; восстановление только при следующем запуске приложения или перезагрузке ТВ. Детект YouTube при этом тоже молчит, т.е. ребёнок смотрит без ограничений. |
| Смена даты/времени | **Закрыто.** Время считается по `SystemClock.elapsedRealtime()` (D-03), настенные часы не влияют (A6). |
| Отключение от сети | **Закрыто.** Приложение полностью локальное, `INTERNET` нет; состояние хранится на диске (DataStore), сеть не требуется. |
| Угадывание ответов | **Закрыто.** Цифровой ввод/варианты обрабатывает движок; неверные ответы дают нарастающий кулдаун (`GateEngine.cooldownFor`), проверено A14. |
| Запуск через голосовой поиск / кнопку пульта | **Закрыто.** У `com.google.android.katniss` нет launcher-активности; запуск через ассистента/по ссылке приводит к тому же `com.google.android.youtube.tv`, который отслеживается (проверено intent `VIEW youtu.be`). |
| PiP / фоновое воспроизведение звука | **Частично.** PiP на прошивке недоступен (нет фичи `picture_in_picture`, YouTube не объявляет `supportsPictureInPicture`) — этого обхода нет. Фоновое аудио: уход YouTube в фон останавливает счётчик (он больше не передний план), отдельный слушатель `MediaSession`/`NotificationListenerService` не реализован — случай не покрыт. |
