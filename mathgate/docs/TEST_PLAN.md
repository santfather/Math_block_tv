# TEST_PLAN — сценарии приёмки

Прогоняется вручную на реальном ТВ. Статусы: `не проверено` / `проходит` / `падает`.

| ID | Сценарий | Ожидание | Статус |
|---|---|---|---|
| A1 | Смотреть YouTube 15 минут непрерывно | Пауза, показ примера | не проверено |
| A2 | Решить пример правильно | Блок снят, счётчик с нуля | не проверено |
| A3 | Ответить неправильно | Блок остаётся, новый пример, пауза | не проверено |
| A4 | BACK / HOME / повторный запуск YouTube при блоке | Блок возвращается | не проверено |
| A5 | 10 мин → закрыть YouTube → открыть → 5 мин | Блок на суммарных 15 мин | не проверено |
| A6 | Смена даты/времени на ТВ | Счётчик не меняется | не проверено |
| A7 | 10 мин → выключить ТВ → включить через час → 5 мин | Блок на 15 мин | не проверено |
| A8 | Блок активен, выключить и включить ТВ | YouTube всё ещё заблокирован | не проверено |
| A9 | Полное отключение питания при блоке (`resetOnPowerLoss=false`) | Блок сохраняется | не проверено |
| A10 | То же при `resetOnPowerLoss=true` | Состояние сброшено | не проверено |
| A11 | Выключить accessibility-сервис в настройках | Сервис возвращается за секунды | не проверено |
| A12 | `adb shell am force-stop <pkg>` во время `Counting` | Сервис поднимается, время восстановлено | не проверено |
| A13 | PIN + «Разблокировать сейчас» | Блок снят, статистика записана | не проверено |
| A14 | 5 неверных PIN подряд | Нарастающая задержка | не проверено |
| A15 | Лимит достигнут при активном YouTube (Android 12) | Блок появляется без участия пользователя | не проверено |
| A16 | После обновления YouTube | A1–A5 проходят, версия записана | не проверено |
