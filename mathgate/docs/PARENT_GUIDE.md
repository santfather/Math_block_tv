# PARENT_GUIDE — инструкция для родителя

Math Gate ограничивает время просмотра YouTube на телевизоре Sony Bravia (Google TV,
Android 12): каждые **15 минут** воспроизведение ставится на паузу и поверх открывается
математический пример. Пока пример не решён правильно, YouTube остаётся заблокированным.

Приложение устанавливается только вручную через `adb` (sideload), в Google Play его нет.
Оно полностью локальное: не требует интернета, не собирает данные.

## Что понадобится

- Телевизор Sony Bravia на Android 12 (проверено на KD-65X85L, BRAVIA 4K VH22).
- Компьютер с `adb` и включённой отладкой по сети на ТВ (параметры разработчика).

## Установка

1. Скачайте подписанный `app-release.apk` (или соберите: `cd mathgate && ./gradlew
   assembleRelease`).
2. Подключитесь к ТВ и выполните установку со всеми разрешениями:

   ```bash
   adb connect <IP-телевизора>:5555
   mathgate/scripts/install.sh <IP-телевизора>:5555
   ```

   Скрипт ставит APK, выдаёт специальные разрешения (для самовосстановления) и запускает
   мастер настройки. Проверить состояние в любой момент: `mathgate/scripts/check-device.sh`.

## Первый запуск (мастер настройки)

Мастер проходит шаги: **Приветствие → Разрешения → Придумать PIN → Подтвердить PIN → Готово**.

1. **Разрешения.** Мастер попросит два разрешения — «Специальные возможности» и «Доступ к
   статистике использования». Оба нужны для надёжной работы; на каждом шаге есть кнопка
   «Открыть», которая ведёт прямо в нужный системный экран.
2. **PIN (4–6 цифр).** Защищает настройки. PIN хранится на телевизоре **только в виде хеша с
   солью** — восстановить забытый PIN нельзя, только задать новый (см. «Если забыли PIN»).

## Ежедневная работа

- Ребёнок смотрит YouTube как обычно. За 60 секунд до лимита появится тихое предупреждение.
- На 15 минутах видео ставится на паузу и появляется пример. Верный ответ — блок снимается и
  просмотр продолжается; неверный — новый пример и небольшая пауза.
- Накопленное время **не сбрасывается** при закрытии YouTube, выключении экрана, перезагрузке и
  отключении питания.

## Родительские настройки

Открыть можно двумя способами: запустить приложение Math Gate из лаунчера **или** (запасной вход)
зажать на экране примера заголовок «Реши пример» (≈1 секунда). Оба входа просят PIN.

Что настраивается:

- **Дневной лимит** — 5–60 минут (по умолчанию 15).
- **Сложность примеров** — уровень 1–4.
- **Режим ответа** — ввод цифрами или выбор из 4 вариантов.
- **Список контролируемых приложений** — YouTube, YouTube Kids, YouTube Music и «Браузер»
  (веб-браузер ТВ). Снятая галочка = приложение не контролируется.
- **Предупреждать за минуту до лимита** — вкл/выкл.
- **Сбрасывать таймер после отключения питания** — по умолчанию выкл.
- **Статистика** — сколько раз блокировало, сколько неверных ответов, общее время просмотра.
- **«Разблокировать сейчас»** — снять текущий блок. **«Сбросить таймер»** — обнулить накопленные
  минуты.

Изменения применяются сразу, без перезапуска приложения.

## Если блок «застрял»

- **Ребёнок не может решить пример** — откройте настройки по PIN и нажмите «Разблокировать
  сейчас».
- **Экран не реагирует / приложение ведёт себя странно** — выключите и включите телевизор
  (пультом → «Выключить», затем включите). Настроенное время и блок сохранятся.
- **После «Остановить» приложение не работает** — откройте Math Gate из лаунчера: службы и
  защита поднимутся автоматически.

## Обновление и удаление

- **Обновление** (с сохранением настроек и PIN): установите новый APK тем же ключом через
  `scripts/install.sh` — команда `adb install -r` сохраняет данные.
- **Полное удаление** (настройки и PIN будут потеряны):

  ```bash
  adb uninstall com.mathgate
  ```

  Затем в настройках ТВ отключите службу Math Gate в разделе «Специальные возможности», если она
  осталась в списке.

## Если забыли PIN

PIN не восстанавливается. Задайте новый, сбросив данные приложения:

```bash
adb shell pm clear com.mathgate
```

После этого приложение откроется как при первом запуске — нужно заново выдать разрешения и
придумать PIN (накопленная статистика сбросится).

## Ограничения (что защита НЕ закрывает)

Полностью закрыть все обходы на обычном телевизоре без прав Device Owner нельзя. Честный список:

- **Удаление приложения и кнопка «Остановить»** — не закрыто. Приложение можно удалить или
  остановить в системных настройках; после остановки защита не восстанавливается, пока
  приложение не запустят снова или ТВ не перезагрузят. **Рекомендация:** заведите ребёнку
  ограниченный (Kids) профиль Google TV, где установка и удаление приложений запрещены.
- **Сторонние клиенты YouTube** (SmartTube и подобные) — автоматически не детектируются, пока их
  пакет не добавлен в список. Не устанавливайте такие приложения; добавьте их пакеты в список
  контролируемых, если они уже стоят.
- **Браузер** — блокируется целиком, если включён в список контролируемых (по умолчанию
  `com.tvwebbrowser.v22` включён). Фильтровать отдельные сайты приложение не умеет: содержимое
  страниц не читается. Если браузер ребёнку не нужен — удалите приложение браузера; если нужен —
  оставьте его в списке, тогда он блокируется так же, как YouTube.
- **Картинка в картинке (PiP)** — на этой прошивке недоступна, отдельного обхода не создаёт.
- **Cast с телефона** — воспроизводится тем же приложением YouTube и подчиняется блокировке.

Закрыто надёжно: выключение службы доступности (самовосстановление за секунды), смена даты и
времени, отключение от сети, подбор ответов, запуск YouTube через голосовой поиск.
