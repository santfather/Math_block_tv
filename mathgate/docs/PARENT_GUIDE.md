# PARENT_GUIDE — инструкция для родителя

Черновик. Итоговая инструкция (установка, настройка, удаление, ограничения) — фаза 10.

## Кратко

Math Gate ограничивает время просмотра YouTube на телевизоре: каждые 15 минут просмотра
показывается математический пример, без правильного ответа YouTube остаётся заблокированным.

## Важно

- Установка только вручную (`adb`), публикации в Google Play нет.
- Приложение полностью локальное: не требует интернета, не собирает данные.
- Это не абсолютная защита: технически подкованный ребёнок может найти обходные пути.
  Честный список ограничений будет заполнен по итогам фазы 8.
